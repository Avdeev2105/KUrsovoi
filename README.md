Программа предназначена для мониторинга технологического процесса в реакторе по параметру «вязкость смеси» (X). 
Программа преобразует измеренные значения в нормированный показатель качества Q(X), 
выполняет оперативный контроль состояния процесса и статистический анализ выборки.
Входные данные: 
Вязкость смеси-(X) [Мпа*с]
Диапазон (X)- от 5 до 80 [Мпа*с]
Количество измерений в выборке - 40.

1. Преобразование Q(X)
$Q(X) = \begin{cases} 5\sqrt{X-20+1}+5,
& \text{при } X < 20 \\ 2(X-32.5)+50,
& \text{при } 20 \le X \le 45 \\ 4\ln(X-45+2)+60,
& \text{при } X > 45 \end{cases}$

2. Оперативный контроль
Превышение базового значения на 3%. Базовое значение Q₀ = 50.00. Сигнализировать при |Q−Q₀| > 3% от Q₀.
Названия состояний студент определяет самостоятельно.


3. Статистический анализ
Для Q[1..19] вычислить: среднее и среднеквадратическое отклонение.

Ручной расчет: 
1. ПРИ X = 10 (меньше 20): Q = 5·((10 − 20 + 1)^0.5) + 5 — подкоренное выражение отрицательно,
поэтому при работе программы такое значение фиксируется как выход за допустимый диапазон X (5…80) и требует проверки исходного измерения.
2. ПРИ X = 32.5 : Q = 2·(32.5 − 32.5) + 50 = 0 + 50 = 50.00
3. ПРИ X = 60 : Q = 4·ln(60 − 45 + 2) + 60 = 4·ln(17) + 60 ≈ 4·2.8332 + 60 ≈ 71.33
