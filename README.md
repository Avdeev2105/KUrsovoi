Вариант 12. Мониторинг реактора: вязкость смеси

Программа мониторит процесс в реакторе по параметру «вязкость смеси» X.
Она преобразует X в нормированный показатель качества Q(X), выполняет
оперативный контроль состояния и статистический анализ выборки.

Входные данные: 
- Вязкость смеси X, мПа·с (по условию).
- Диапазон X: от 5 до 80 мПа·с (по условию).
- Количество измерений в выборке: 40 (по условию).

1. Преобразования Q(X)

$$
Q(X)=\begin{cases}
5\sqrt{X-19}+5, & 19 \le X < 20 \\
2(X-32.5)+50, & 20 \le X \le 45 \\
4\ln(X-43)+60, & X > 45
\end{cases}
$$

Область определения Q: X ∈ [19; 80]. При X < 19 подкоренное выражение
первой ветви отрицательно, поэтому Q не определена, и происходит повторный ввод числа.

Оперативный контроль: 
Базовое значение Q₀ = 50.00. Допуск 3 % от Q₀ = 1.50.
Отклонение d = |Q − Q₀|:

Условие и состояние
 d ≤ 1.50 (≤ 3 %)  НОРМА 
 1.50 < d ≤ 5.00 (3–10 %)  ПРЕДУПРЕЖДЕНИЕ 
 d > 5.00 (> 10 %)  АВАРИЯ 

Статический анализ: 
Для Q[1..19] вычисляются среднее и среднеквадратическое отклонение
(выборочное, делитель n − 1).

Ручной расчет: 
X = 19.5 (1-я ветвь): Q = 5·√(19.5 − 19) + 5 = 5·0.7071 + 5 ≈ 8.54(АВАРИЯ)
X = 32.5 (2-я ветвь): Q = 2·(32.5 − 32.5) + 50 = 50.00(НОРМА)
X = 34 (2-я ветвь): Q = 2·(34 − 32.5) + 50 = 3 + 50 = 53.00(ПРЕДУПРЕЖДЕНИЕ)
X = 60 (3-я ветвь): Q = 4·ln(60 − 43) + 60 = 4·ln 17 + 60 ≈ 4·2.8332 + 60 ≈ 71.33(АВАРИЯ)
